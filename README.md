# programa-turnos
Sistema de Gestión de Turnos

Aplicación web desarrollada en Java para gestionar turnos de atención en una entidad gubernamental; permite registrar ciudadanos, asignar turnos, filtrar por estado o fecha y actualizar su estado.

Tecnologías utilizadas

- Java 17
- JSP y Servlets (Jakarta EE)
- JPA con Hibernate
- MySQL (a través de XAMPP)
- Apache Tomcat 9
- IntelliJ IDEA 2023.2.2 con SmartTomcat
- Maven
- CSS personalizado centralizado (`style.css`)


Requisitos previos

- Java JDK 17
- Apache Tomcat 9
- XAMPP con MySQL activo
- IntelliJ IDEA con plugin **SmartTomcat**
- Maven (incluido en IntelliJ)
- Navegador web



Configuración del entorno

Base de datos (MySQL)

1. Abre XAMPP y enciende **MySQL**.

2. Abre phpMyAdmin (`http://localhost/phpmyadmin/`) y crea una base de datos llamada “turnero”.

3. Haz clic en la base de datos turnero, se actualizarán los datos que sean ingresados en la página http://localhost:8080/programa
